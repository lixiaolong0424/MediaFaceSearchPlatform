〇、Agent 工作方式（最重要，先读）
你是本项目的唯一实现者。目标不是「写一堆 py 文件」，而是交付一个可安装、可扫描、可检索、可导出、可验收的本地工具。请遵守以下工作纪律：
1. 不许并行阶段。 P0 未通过验收前，禁止写 P2 的人脸管线代码；schema 未冻结前，禁止写业务逻辑。每完成一个阶段，先跑验收用例，全部通过后向我汇报再进入下一阶段。
2. 每个模块必须可独立运行。 每个 .py 都要支持 --dry-run、--shard N/M、--root <path>。单文件失败只写 error 字段，绝不中断整批。
3. 所有路径用 pathlib.Path，禁止字符串拼接。 全程使用绝对路径。日志双写 stdout 与 ./logs/<date>.log，每条日志带 session_id。
4. 参数一律进 config.yaml，禁止硬编码。 阈值、采样率、分页大小、预算上限，一处定义，全局读取。
5. 遇到规格未覆盖的边界情况，先问我，不要自行决定。 尤其涉及：默认阈值、抽帧密度、删除策略、隐私开关。
6. 每次交付物必须附带：可执行的验收命令 + 预期输出 + 失败判定标准。 没有验收标准的代码视为未完成。
7. 先输出实施计划（拆成若干 milestone，每个 milestone 列出产出文件与验收方式），经我确认后再动手写代码。

一、项目概览
1.1 目标（必须全部做到）
用户指定一个或多个本地绝对路径，递归扫描其中的照片与视频，建立离线索引。
支持三种检索输入：文字描述 / 图片 / 视频；图片与视频输入时可勾选「精确找人」。
Tab1 照片墙：把该目录下检测到的所有人脸铺成可筛选、可分页、可滚动的瀑布流（浏览模式，不依赖任何 query）。
Tab2 命中清单：一次检索的命中结果，带时间码（视频）或日期（照片）、完整绝对路径、相似度 badge。
卡片支持：▶ 预览（视频从指定时间点片段播放）、📂 打开所在文件夹（按钮，非右键）、找同款（人脸向量召回）。
导出 TSV：三入口（全库清单 / 当前照片墙筛选结果 / 命中清单），tab 分隔、存在性校验（DEAD 标记）、幂等排序。
增量扫描：只处理新增/修改/移动的文件；扫描异步、可见进度、不阻塞浏览。
1.2 明确不做（写死，防 scope creep）
人物自动聚类分人 UI、人名管理、社交分享、地图相册、手机备份、云同步。
视频转码、语音识别、字幕理解、车牌/身份证识别。
浏览器内剪辑或时间轴编辑器（交付物是「时间点+路径+TSV」，剪辑交下游）。
多人脸合照的矩形框选指定某人（靠「点脸→找同款」解决）。
结构化 TXT 供下游 agent 剪辑归档。
依赖 Immich 或任何外部相册系统的数据库与 API。
Docker 部署主应用（Qdrant 除外）。
1.3 运行环境（Windows 硬约束）
目标平台：Windows 10/11 22H2+，x86_64，裸机，无 Docker（Qdrant 除外）
Python：3.10+（python.org 安装包，禁止 Microsoft Store 版——其 KnownFolder 重定向会破坏相对路径）
GPU：NVIDIA RTX 3090 24GB，驱动 ≥55x，CUDA 由 torch 轮子自带（pip install torch --index-url https://download.pytorch.org/whl/cu126）
onnxruntime：必须安装 onnxruntime-gpu（非 CPU 版），确认 ort.get_available_providers() 包含 CUDAExecutionProvider。注意：新版 onnxruntime（≥1.23）已移除 ort.get_device()，需用 ort.get_available_providers() 替代。
项目根目录：D:\DATA\PROJECT\建设多媒体整理系统（所有代码、日志、数据库、缓存、导出物均在此目录下）。素材根目录（media_root）：由用户在 UI 或 config.yaml 中指定，默认 E:\（用户可指定任意目录，代码中一律通过 config.yaml 的 media_root 读取，禁止硬编码）。

项目根目录（project_root）：D:\DATA\PROJECT\建设多媒体整理系统（所有代码、日志、数据库、缓存、导出物均在此目录下）；派生物与索引目录：${project_root}\data\nvme，硬上限 300GB
权重目录：${project_root}\weights（若权重在中文路径下，用 mklink 映射到此处）
进程：用户登录会话内常驻（不用 Windows 服务），start.bat 双击启动，任务计划程序做定时增量扫描
终端：PowerShell 5.1/7 + cmd 兼容；所有脚本支持 python xx.py --root "${media_root}"
Qdrant：Docker 容器运行（docker.m.daocloud.io/qdrant/qdrant:latest 镜像拉取），绑定 127.0.0.1:6333
环境变量：PYTHONUTF8=1（全局启用 UTF-8 模式，防止中文路径乱码）；TMP/TEMP/TMPDIR 指向 ${project_root}\tmp（建议指向 NVMe 分区以避免 C 盘空间不足）
为什么不用 Windows 服务跑 Streamlit： Session 0 隔离会让 explorer /select, 等桌面交互型 subprocess 静默失败或弹到不可见会话。正确做法是「start.bat 双击启动 + 开机启动文件夹快捷方式」，或用任务计划程序「登录时触发」。

四、数据模型与一致性
4.1 schema（state.db，WAL 模式）
PRAGMA journal_mode=WAL; PRAGMA synchronous=NORMAL;CREATE TABLE libraries (root TEXT PRIMARY KEY, last_scan TEXT, status TEXT, indexed_faces INTEGER DEFAULT 0);CREATE TABLE files (  file_id INTEGER PRIMARY KEY, path TEXT UNIQUE NOT NULL, path_hash TEXT,  inode INTEGER, size INTEGER, mtime INTEGER,  kind TEXT CHECK(kind IN ('photo','video','unknown')),  status TEXT DEFAULT 'pending',  phash TEXT, captured_at TEXT, time_source TEXT, visible INTEGER DEFAULT 1,  kind_hint TEXT, indexed_at TEXT, updated_at TEXT);CREATE INDEX idx_files_status ON files(status);CREATE INDEX idx_files_inode ON files(inode);CREATE INDEX idx_files_path_hash ON files(path_hash);CREATE TABLE shots (file_id INTEGER, shot_ix INTEGER, shot_start REAL, shot_end REAL, n_frames INTEGER, PRIMARY KEY(file_id,shot_ix));CREATE TABLE file_encoding (  file_id INTEGER, model TEXT, status TEXT, n_frames INTEGER, error TEXT, encoded_at TEXT,  PRIMARY KEY(file_id, model));CREATE TABLE face_records (  face_id INTEGER PRIMARY KEY, file_id INTEGER, shot_ix INTEGER,  bbox TEXT, quality REAL, track_id INTEGER, thumb_path TEXT,  status TEXT DEFAULT 'alive', captured_at TEXT,  hidden INTEGER DEFAULT 0);CREATE INDEX idx_face_browse ON face_records(status, captured_at DESC);CREATE INDEX idx_face_file ON face_records(file_id, shot_ix);CREATE TABLE person_labels (face_group_id INTEGER, name TEXT, created_at TEXT);CREATE TABLE judgments (query_id TEXT, doc_id TEXT, rank INTEGER, score REAL, label INTEGER, at TEXT);CREATE TABLE dead_letter (file_id INTEGER, stage TEXT, attempt INTEGER, error TEXT, at TEXT);CREATE TABLE audit_log (who TEXT, at TEXT, what TEXT, before TEXT, after TEXT);CREATE TABLE db_version (v INTEGER PRIMARY KEY);
4.2 三条铁律
去重跳过的文件，必须在 file_encoding 里为每个模型各记一行 skipped_dup，否则统计数对不上。
文件被删除只标 status=missing，绝不物理删记录；改名/移动通过 inode 判定，只更新 path，保留所有向量与人脸记录。
两阶段入库保一致性：先写 file_encoding.status=pending → 写 Qdrant → 最后 status=done + encoded_at。检索 L4 只 join done 的文件。提供 repair（重试 pending/error ≤3 次，超限入死信表）与 reconcile（比对 sqlite 与 Qdrant point 数，输出差异报告）。
4.3 schema 迁移（P0 前置条件）
db_version 单行表 + migrations/001_init.sql 增量脚本，启动时顺序执行大于当前版本的脚本，包在一个事务里，失败回滚。规则：幂等、只增不改（不改列类型不删列）、带 down 注释。违反则第一次改 schema 即事故。

五、A 语义管线 L1–L4
L1 清单扫描：后缀白名单 .jpg .jpeg .png .webp .mp4 .mov .mkv .avi .m4v；stat 取 mtime/inode/size，path_hash=md5(相对路径)；维护轻量索引表 path_hash → (inode,mtime,size) 使增量比对秒级完成；输出五类 new / modified / moved / unchanged / missing。不解码、不读内容。
L2a pHash 去重（仅图片）：64 位感知哈希，汉明距离 ≤8 视为近重复；保留分辨率更高、mtime 更新者；另一记 skipped_dup。
L2b 镜头切分与抽帧（精度天花板）：
video:  scene_detect_threshold: 30.0  min_shot_len_sec: 0.8  max_frames_per_shot: 5  keyframe_short_edge: 384  long_shot_threshold_sec: 10.0  long_shot_sample_per_sec: 1photo:  keyframe_short_edge: 384
同阶段顺手读 EXIF：优先级 DateTimeOriginal(含GPS时区) → QuickTime Creation Time → 文件名日期 → mtime，落 captured_at + time_source。不可在渲染时实时读。
失败处理：抽帧后校验文件大小>2KB 且非全黑（均值>5），失败记 error 重试 1 次；单文件失败绝不中断整批；镜头数异常告警（每小时镜头数超出 [30,600] 标 warn；单镜头超 30 分钟强制按 5 分钟切段）。
L2c 编码（唯一在线语义模型）：
semantic_model:  model_path: E:/weights/qwen3-vl-embedding-2b  offline_only: true  dimension: 2048  mrl_dim: null  dtype: bfloat16  batch_size: 16  instruct_query: "检索与输入画面内容相似的视频片段"  thresh_default: 0.55  recall_k: 400  rerank_topk: 50
入库 payload 扁平化且禁放模型相关字段：kind,file_id,shot_ix,sec,shot_start,shot_end,path,thumb_path；upsert 语义。
L4 后处理（永远挂，与模型无关）： 1. 文件级聚合 2. 时序一致性聚类（相邻且间隔<3s 的命中镜头合并为一个时间段） 3. 防长视频霸榜（排序依据 = 文件内命中镜头数 × 平均分） 4. 检索侧 face→shot 去重（同一 (file_id,shot_ix) 内多张人脸取最高分代表，卡片标注「该镜头内出现 N 次」） 5. 精排接入点 stage1 k=400 → stage2 Reranker Top-50 → stage3 L4

六、B 人脸管线 F1–F3（A 方案·稠密预计算）
选型理由（已拍板）：查询延迟从 2~10s 降至 80~250ms（约 20~50 倍），且是唯一能让 P3 聚类成立的路径。成本前置到索引期。
人脸模型选型：InsightFace buffalo_l（SCRFD 检测 + ArcFace 识别）

7.2 自适应截断（已拍板，替代固定阈值）
召回 k=400 后按分数降序，在 top-50 内找最大 gap 做自然截断，阈值只做兜底：
def adaptive_cut(scores, k_hard=200, min_score=0.55, gap_min=0.03):    top = scores[:min(k_hard, len(scores))]    for i in range(1, min(50, len(top))):        if top[i-1] - top[i] >= gap_min and top[i] >= min_score:            return top[:i]    return [s for s in top if s >= min_score]
前端必须显示「已截断至 N 条（第 N+1 条分数 0.61）」。

20.3 权重路径注意事项
项目权重目录：${project_root}\weights\
风险：中文目录名 + 空格 + C 盘桌面（可能被 OneDrive 同步/云占位符化）；建议将权重通过 mklink 映射到 ${project_root}\weights\ 下
建议方案：用目录联接（junction）建英文短入口（管理员 PowerShell）：
cmd /c 'mklink /J "${project_root}\weights\qwen" "C:\Users\lixiaolong\Desktop\建设多媒体整理系统\weight\Qwen3-VL-Embedding-2B"'cmd /c 'mklink /J "${project_root}\weights\buffalo_l" "C:\Users\lixiaolong\Desktop\建设多媒体整理系统\weight\buffalo_l"'
代码只认 ${project_root}\weights\...。

docker run -d --name qdrant -p 6333:6333 -p 6334:6334 ^  -v qdrant_storage:/qdrant/storage ^  -v qdrant_snapshots:/qdrant/snapshots ^  -e QDRANT__SERVICE__HOST=0.0.0.0 ^  -e QDRANT__TELEMETRY_DISABLED=true ^  --restart unless-stopped ^  qdrant/qdrant
